# 源码构建与项目结构

## 不需要先建一个全新的Visual Studio项目

本包的C#文件通过build.ps1直接交给随包Roslyn编译器，所有必要的Mod源文件都在Source/AICoopCompanion。没有把反编译的Verse/RimWorld源码或游戏DLL放进来。

## 构建前准备

1. 保留完整源码版目录，不要只拿Source文件夹。
2. 安装你自己的环世界1.6并记下游戏目录。
3. Windows需能运行.NET Framework 4.7.2及以上程序。没有时从微软官方安装.NET Framework 4.8，不从陌生网站下载单个系统DLL。
4. 关闭游戏。
5. 确认packages里有compilers、harmony、net471目录。

## 编译步骤

最简单：双击“编译Mod.cmd”，在英文提示“RimWorld install directory”后粘贴游戏目录并回车。它指的是游戏安装目录，不是exe文件本身。

或打开PowerShell，切换到源码根目录：

    Set-Location "你的源码目录"
    powershell -NoProfile -ExecutionPolicy Bypass -File .\Source\AICoopCompanion\build.ps1 -GamePath "你的环世界安装目录"

也可以先设置RIMWORLD_GAME_PATH环境变量；未传参数且源码恰好位于游戏根目录时，脚本会识别当前目录。

成功标志：编译器无错误退出，Mods/AICoopCompanion/Assemblies/AICoopCompanion.dll生成或更新时间变化。出现CS开头错误需要修复代码后再编译，不要把旧DLL误当成本次成功产物。

游戏引用来自你自己的RimWorldWin64_Data/Managed：
Assembly-CSharp.dll、UnityEngine.CoreModule.dll、UnityEngine.IMGUIModule.dll、UnityEngine.TextRenderingModule.dll、netstandard.dll。
请勿把这些引用复制进GitHub仓库或玩家包。

源码包保留Harmony 2.3.3作为编译API引用；玩家版提供独立Harmony Mod 2.4.2.0。构建不复制Harmony DLL，运行时由前置模组提供。更换Harmony版本时应重新测试兼容性。

## 安装构建产物

把完整Mods/AICoopCompanion文件夹复制到游戏Mods，先把旧版本移到目录外备份。不能只复制DLL而漏掉Defs、预设、攻略和插件。另装并启用独立Harmony，然后启用本Mod并重启游戏。

## 修改Python/JavaScript

- 插件入口：Mods/AICoopCompanion/DeepSeekHarnessPlugin/index.js。
- Python桥接：aicoop_mcp.py。
- CLI入口：aicoop_cli.py。
- 全工具目录、参数与示例：aicoop_tools.py。
- 提示词：rimworld_harness_prompt.txt。
- 插件安装：install.ps1。

Python至少3.10，只有标准库，无需pip。Node/Harness请自行按DSH发布者要求安装。Node.js执行index.js的语法检查不等于完整插件运行；插件需要Harness提供的Cordis服务。

检查命令：

    node --check Mods/AICoopCompanion/DeepSeekHarnessPlugin/index.js
    python -X utf8 -B Mods/AICoopCompanion/DeepSeekHarnessPlugin/aicoop_tools.py
    python -X utf8 -B Mods/AICoopCompanion/DeepSeekHarnessPlugin/aicoop_cli.py tools

这些检查不会向模型发送请求；最后两条列出/验证工具目录。ping需要游戏已进入存档；execute/call会真的执行操作，请谨慎。

## DSH与玩家版

DSH由玩家自己安装，不在源码中包含DSH、Node、npm锁文件或自动还原DSH的脚本。插件安装见本文件夹的玩家安装与使用说明.txt。
编译后把完整Mods/AICoopCompanion作为玩家版Mod/AICoopCompanion；沿用干净玩家版中的Python、独立Harmony和安装脚本。不要复制已经安装产生的install-state.json或个人配置。
本次交付不生成压缩包。修改后请在新的测试存档实测，再分享完整玩家版文件夹。
