# 建设、房间与预设关联链

普通房间：读取地图可建区域和现有建筑 -> `designate_area` 清理树木、矿石岩体或待拆建筑 -> 同轮先用 `dump_stockpile` 建至少 7x7 临时垃圾区，再用 `designate_area(action=haul_chunks)` 搬石块 -> `build_room` 放置一个房间 -> 读取蓝图材料缺口 -> 用伐木、采矿、搬运补料 -> 等殖民者自动施工。

预设房间：先用 `reference_index(category=preset)` 查看 16 个文件名和用途 -> 只用 `reference_read(category=preset,file=...)` 读取当前需要的一份 -> `preset_build` 使用同一文件名放置一个房间 -> 未研究或未制作设施暂时跳过 -> 当前确实需要时完成研究/制作前置并 `preset_retry` 一次，暂时用不到时不为它研究 -> 房间稳定可用后 `preset_done`。每次只建设一个房间，不按文件顺序连续建设。

外围防御：居住区边界至少13x13且建设稳定 -> `build_perimeter`/`F mapID [岩石材质]` 包围所有居住区，包括分离部分，只建一层矩形石墙；墙不占居住区，不额外要求四格，仅受不可建地形阻挡时绕行，左右留口不建门 -> `defense` 在开口外放陷阱。新圈内记录的旧外墙自动拆除指定/取消旧蓝图，重合段和房间墙保留。收到 PERIMETER_EXPANDED 后按需调整。预计精英袭击压缩前点数超过1000时，墙内使用 `room_defense_active_turrets.txt`；`room_defense_gate_battery.txt` 对齐左右开口之一，外墙长度不足则扩建。主动炮台距其他建筑至少2格。

关联限制：普通房间 13x13、单一用途、房间之间至少空一格；预设允许整体旋转，房间内可以在不改变房间类型、边界、过道和相对布局的前提下增删或调整设施。材料不足是补料条件，不是重复放置同一蓝图的理由。
