# 殖民地预设格式
# 本目录每个中文名.txt保存一个房间，数量不限。新增或修改文件后工具会重新读取；有ROOM与FOOTPRINT等数据才会成为预设，说明文件不会成为房间。
#
# 每个中文名.txt文件是一套单房间预设。玩家可增加卫生间等自定义用途，原版不必存在同名房间。预设按需求使用：
# AI 只有在当前确实需要某个房间时才输出 PRESET <文件名>，用不到的文件和房间跳过。
# PRESET 自动寻找合法落点；普通房间先按13x13边线对齐紧贴共墙，再检查门，不为对门而错位或换拼接侧。PRESET <文件名> <mapID> <优先左下角x> <优先左下角z> [旋转0-3] 可指定选址优先位置，以结果 origin 为准。每次只建一个房间；需要原位旋转或无法对齐时弹窗等待玩家同意，取消不施工。
# 完成当前房间后输出 PRESET_DONE <房间ID>；需要其他房间时重新选择另一个文件。
# 坐标使用目标地图坐标；协议行中的 MAP 会由 AI 替换为当前地图 ID。
#
# 示例：
# ROOM id=R01 purpose=宿舍 priority=1
# Q MAP 20 20 32 32 Wood
# B MAP Bed 22 22 0 Wood
# END_ROOM
# ROOM id=R02 purpose=厨房 priority=2
# Q MAP 40 20 52 32 Wood
# B MAP FueledStove 45 25 0 Steel
# END_ROOM
#
# 支持写入现有协议命令（Q、B、G、S、P、C、T 等），每行一条；也可以使用 TEMPLATE、
# FOOTPRINT、LAYOUT、FACILITIES 等文字描述作为相对布局图纸。AI 需要选择地图锚点并换算坐标。
# FOOTPRINT 描述占地尺寸；BUILD 记录墙、门及设施的相对坐标、朝向和材料，FLOOR/FLOOR_HASH/ZONE/STATE 记录地板、区域和物品状态。房间先边线对齐紧贴，然后检查门；共享墙门只保留已有房间的一份。原位旋转 90/180/270 度先询问玩家。仍无法对齐时，同意后才继续并请求玩家调整连接处。用途不变时可调整设施，但不得破坏封闭性。
# 不要写 PLAN、GUIDE_DONE、
# PRESET 或 PRESET_DONE。文件放入本目录后，重启游戏或重新载入 Mod 才会刷新文件列表。
# 防御专用预设：大门防御阵地.txt（大门附近，自动对齐普通外墙的左右开口并在需要时扩展墙体）；
# 主动炮台.txt（墙内主动炮台，选址时与其他建筑至少间隔两格）。
