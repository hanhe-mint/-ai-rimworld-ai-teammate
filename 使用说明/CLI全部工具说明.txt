# 全部 CLI 工具说明

本表由随包 aicoop_tools.py 生成，目录版本 5，共 78 项。不要把示例中的地图ID、殖民者ID、坐标或工作序列直接用到自己的存档。

普通玩家在游戏/Harness聊天即可，不需要手打CLI。Harness通过 cli_execute.commands 提交下列原始指令，每行一条；直接终端用法为 python aicoop_cli.py call 工具名 --arg 名称=值。管道只支持本机Windows。涉及真实游戏状态的调用会实际改变存档，请先备份；权限拒绝不应绕过。

参数标记“必填”的均需提供；JSON示例和原始CLI示例描述的是同一工具调用。工作优先级工具的数字数量必须以实际 WORK_PRIORITY_ORDER 为准，不是固定7项。

## work_priorities

按 WORK_PRIORITY_ORDER 一次设置一名 AI 殖民者全部工作优先级；禁用项为0，低技能不要设1或2。

权限键：C.work；分类：pawns。

- map_id（integer，必填）：状态中的地图 ID。
- pawn_id（integer，必填）：AI殖民者ID
- priorities（string，必填）：全部0到4的数字，逗号分隔；数量必须匹配 WORK_PRIORITY_ORDER

JSON参数示例：

```json
{
  "map_id": 0,
  "pawn_id": 123,
  "priorities": "1,3,3,3,2,3,3"
}
```

原始CLI示例：

```text
C 0 work 123 1,3,3,3,2,3,3
```

## plan

记录一条公开工作计划，不执行隐藏思维链。

权限键：none；分类：control。

- text（string，必填）：公开计划文本；不能包含换行。

JSON参数示例：

```json
{
  "text": "先稳定食物和住房"
}
```

原始CLI示例：

```text
PLAN 先稳定食物和住房
```

WORLD launch 8300 456 land

## world_trade

在设置允许 AI 直接交易时买入或卖出物品。

权限键：WORLD.trade；分类：world。

- world_object_id（integer，必填）：可贸易世界对象 ID。
- pawn_id（integer，必填）：AI 谈判者 ID。
- direction（string，必填）：交易方向。；可选值：buy、sell
- thing_def（string，必填）：交易物 ThingDef。
- count（integer，必填）：交易数量。

JSON参数示例：

```json
{
  "world_object_id": 3001,
  "pawn_id": 101,
  "direction": "buy",
  "thing_def": "Steel",
  "count": 100
}
```

原始CLI示例：

```text
WORLD trade 3001 101 buy Steel 100
```
