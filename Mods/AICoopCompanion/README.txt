AI Coop Companion - RimWorld 1.6（仅外接 Agent）

1. 在 Mod 菜单启用本 Mod，载入存档。新建游戏可选择“AI 协作：迫降”，前两名殖民者属于玩家，后两名属于 AI。
2. 在 DeepSeek Harness 中选择“环世界 AI 队友”预设，新建会话。预设通过绝对路径加载 DeepSeekHarnessPlugin/index.js，不修改 Harness 核心。
3. 点击 /rimworld-connect 或发送“连接游戏”。进入存档后桥接自动就绪，但只有用户手动连接才开始协作。
4. 每轮可以调用多次 cli_execute，完成后回复玩家；插件等待 Mod 设置中的决策间隔后再注入下一轮游戏信息。用 /rimworld-stop、/rimworld-disconnect 或“停止”结束协作，重新连接后恢复。
5. Mod 设置保留 0–120 秒决策间隔、思考时暂停、最短工作时间、日志上限、操作权限和交易执行方式；不提供内置 API、模型或模式切换。模型与会话上下文由 Harness 管理。
6. 游戏下方“AI 协作”界面可切换聊天和日志。聊天框与 Harness 均可输入需求；AI 请求通知提供立即处理、稍后处理和拒绝三个回复。插件更新后重启 Harness，DLL 更新后重启游戏。

殖民者栏不增加玩家/AI 灰框。每个原版地图或远征分组内会自动保持玩家殖民者在前、AI 殖民者在后；招募新成员后自动重新排序。

所有当前可用的 AI 游戏操作均由 DeepSeekHarnessPlugin\aicoop_tools.py 导出为独立 CLI 工具。工具名、中文说明、权限键、参数 Schema 和示例参数以 `python DeepSeekHarnessPlugin\aicoop_cli.py tools` 的输出为准；Harness Agent 使用 cli_execute.commands 提交 CLI 指令。使用 C mapID work pawnID 1,3,0,... 一次设置该 AI 殖民者的全部工作优先级；严格遵循 WORK_PRIORITY_ORDER，禁用工作填 0，按技能分工。

AI 会按迫降快速入门流程推进：安全与威胁、房间和床、仓储与食物种植、电力和照明、工作台生产、研究、防御扩建、终局。不会更改游戏设置，也不会暂停或调整游戏速度。树木使用伐木操作，非树植物才使用割除操作，成熟作物使用收获操作。
`build_room` 可一次放置矩形墙体和门蓝图；`build` 可放置床、照明、发电机、电池、电线、工作台等已解锁建筑；所有建筑仍消耗原版材料并由殖民者正常施工。
`bed_mode` 可将已建成的床切换为殖民者床、囚犯床、奴隶床或医疗床；床位状态会在 AI 状态的 BLD 行中显示。
AI 操作只允许由 AI 所属殖民者授权，并会检查地图边界、可行走性、建筑研究、材料类型、区域、配方、研究前置、敌对关系、工作能力和参数范围。
基础版已提供人员设置、逐小时作息、活动区、方案、仓储类别和专属筛选、温控、自动重建、批量地板/电缆、防御模板、装备丢弃/携带/主动使用、囚犯互动、手术账单、动物训练、自动深钻井、高级生产账单、Ideology 文化仪式和世界地图操作等独立工具。具体能力和参数以 CLI 工具目录为准；派系许可、异象、机械体、基因、食尸鬼、Boss 等尚未实现的 DLC 特殊交互仍只会请求玩家处理。
世界地图工具受权限页中的组建商队、移动商队、装载、发射和贸易项目控制。默认组建/移动/装载/发射为“询问玩家”，贸易为“禁止”；玩家可在设置中改为允许或询问。AI 不提供接取任务工具，需要接取时请求玩家操作。Agent 设置中的“AI 交易执行方式”决定允许贸易后是打开原版窗口由玩家操作，还是由 AI 使用原版 TradeSession 自动买卖。其他 Ideology 编辑、派系许可、异象、机械体、基因、食尸鬼、Boss 等 DLC 或特殊交互仍不会由 AI 操作。
AI 状态由模组直接读取 RimWorld 当前进程内的 Game、Map、Pawn 和 Def 对象生成，不使用截图、摄像机、纹理或视觉模型。

外接 Agent 工作方式：
首轮发送固定基线与完整状态，后续提供游戏通知、关键变化和执行结果、拒绝、错误。AI 只能通过 cli_execute.commands 调用游戏工具；本轮完成后给出最终回答，回复显示在游戏内聊天页。聊天框 Enter 发送，不关闭窗口；玩家消息和请求回复不受决策间隔限制。
存档保存日志、进度和 Agent 最新执行记录；读档后旧管道失效，插件按新存档重建状态。若连接失败，确认游戏已载入存档和本 Mod 已启用。
插件安装、按需资料和手动连接详见 DeepSeekHarnessPlugin/README.md。DSH 0.1.7 起使用 install-modern.ps1，通过 -DshUserRoot 指定实际用户目录、-Profile 指定当前配置。不要使用旧版 install.ps1 注册新版 DSH。聊天框 Enter 发送，Shift+Enter 换行。
