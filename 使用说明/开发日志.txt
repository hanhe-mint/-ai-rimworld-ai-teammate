环世界AI队友 0.5.0 开发日志
2026年10月14日

【重要】适配 RimWorld 1.7（Waylith 引擎）。同时保留 1.6 支持，一份源码编译出的同一个 DLL 可在两个版本运行。
本版本仍需 DeepSeek Harness（DSH）0.2.0系列及以上；本次验证版本为0.2.0-rc.2。

一、适配 RimWorld 1.7
1. 1.7 将游戏从 Unity 迁移到自研 Waylith 引擎（.NET 10 / CoreCLR），编译环境与运行时均发生变化，本次完成全部适配。
2. 构建脚本现在自动识别两种游戏布局：1.6 的程序集位于 RimWorldWin64_Data/Managed，1.7 则直接位于游戏根目录（以是否存在 UnityStubs.dll 判定）。同一份源码在两个版本下均可直接编译，无需切换分支或改配置。
3. 引用程序集按版本自动选择：1.6 使用 4 个 UnityEngine 模块与 Mono 的 mscorlib，1.7 使用 UnityStubs 与 .NET 10 核心库。
4. 修复 1.7 中 ChatInput 换行失效的问题。1.7 移除了 TextEditor.ReplaceSelection，该 API 原用于聊天框 Shift+Enter 换行；现改为反射调用，运行时若不存在则手动插入换行并同步光标，1.6 与 1.7 行为一致。
5. About.xml 的 supportedVersions 同时声明 1.6 与 1.7，避免玩家在 1.7 下看到黄色版本警告。

二、兼容性验证
1. 全部 14000 余行 C# 源码通过 1.7 程序集编译，无错误无警告。
2. 26 个 Harmony 补丁、53 处私有成员反射、5 处 UnityEngine 直接引用、72 处引擎 UI 调用，均在 1.7 环境中完成编译期与实机加载验证。
3. 实机确认：Mod 主面板正常打开，命名管道 \\.\pipe\AICoopCompanion-v1 正常建立，界面与交互正常。
4. 完整的技术记录、耦合面清单与逐项风险见仓库 使用说明/1.7兼容性普查报告.md。

三、其他
1. 版本号由 0.4.2 更新为 0.5.0，涉及 About.xml、VERSION.txt、AssemblyInfo.cs、插件的 package.json 与 MCP 服务版本。
2. README 增加 1.7 适配说明章节，源码说明同步更新编译要求（不再限定 1.6）。

【说明】1.7 目前位于 Steam 的 unstable 测试分支，主分支仍为 1.6。1.6 与 1.7 的存档双向兼容，切换测试分支不影响现有存档。

环世界AI队友 0.4.2 开发日志
2026年9月30日

【重要】本版本仅支持 DeepSeek Harness（DSH）0.2.0系列及以上，不再支持0.1.x！
本次验证版本为0.2.0-rc.2。支持本机Windows上的DSH网页端与官方桌面版；请同时更新Mod和插件，并重启游戏与Harness。

一、新增功能
1. 安装程序支持识别网页端和官方桌面版的配置位置。存在多个配置时会让玩家选择，避免装到另一端。

二、体验优化
1. DSH兼容范围由0.1.x改为0.2.0系列及以上，网页端与官方桌面版使用同一套环世界插件。
2. 安装位置由默认网页端改为按实际配置选择：网页端通常为web，官方桌面版为desktop。安装教程同步补充两种用法。
3. 旧插件安装入口改为使用新版安装方式，不再写入已经停用的旧预设目录。
4. 环境不兼容时的提示改为明确说明需要更新Harness，减少不知道为何加载失败的情况。

三、问题修复
1. 修复了旧版依赖要求导致DSH 0.2.0拒绝加载插件的bug。
2. 修复了DSH 0.2.0中“AI提示词”功能加载失败的bug。
3. 修复了安装默认只选择网页端配置、官方桌面版可能看不到环世界模式的bug。

升级提醒
请备份存档、个人提示词、学习内容与自制预设，移走旧Mod后再安装新版。Tools仍在玩家包最外层，与安装、卸载脚本并列，不要复制进Mod。
DSH需要自行安装，模型/API仍在DSH中配置。本包不附带DSH本体，也不修改其核心程序。
两端均要求DSH服务运行在游戏所在的Windows电脑上；远程服务器、WSL和容器无法直接访问游戏连接。
已经过0.2.0-rc.2真实运行时加载、工具和命令注册、消息格式、提示词权限及安装流程检查；尚未完成游戏内端到端实战验证，不保证未来DSH版本改动后仍无需适配。
