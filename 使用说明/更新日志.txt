环世界AI队友 0.3.5 更新日志
作者：寒荷mint
日期：2026-09-24
适用游戏：RimWorld 1.6（Windows）

【重要：必须使用 DeepSeek Harness（DSH）0.1.7 及以上版本，低于 0.1.7 不支持本次更新！】
本次具体适配版本为 0.1.7-alpha.1；不代表所有后续版本均已验证。升级时请同时更新游戏 Mod 和 DSH 插件，并重启两端。

一、新增功能
1. 新增“聊天时暂停游戏”设置，打开聊天页面时可自动暂停游戏。
2. 新增模型输出截断后的自动续接：检测到 max-tokens 事件后，发送一次“继续”玩家消息。普通错误、主动停止或断连不会触发续接；续接可能产生额外模型费用。
3. 队友预设新增联网搜索和网页读取能力，实际可用性取决于网络及 Harness 搜索服务配置。
4. 新增只读地图查询工具 MAP_SCAN mapID x1 z1 x2 z2 [offset]，可查看指定范围的地形、屋顶、区域、物品、人物、蓝图及设施状态。游戏坐标 z 对应二维地图的 y，每页返回 128 格，可使用 next 偏移继续读取。
5. 新增围墙范围存档记录；居住区扩展超出围墙范围后，在下一轮游戏信息中提醒 AI。
6. 新增“玩家可控制 AI 殖民者，但 AI 不可控制玩家殖民者”操控选项。

二、体验优化
1. 游戏聊天输入由单行改为多行，Enter 改为发送消息，Shift+Enter 改为换行，同时保留发送按钮。
2. 游戏聊天由上下文注入改为 Harness 原生玩家消息气泡；游戏状态仍通过插件上下文发送。
3. 自动回合的自然回复由计划式长段输出改为用一句队友口吻概括“做了什么、下一步做什么”；直接回答玩家问题和聊天不受一句限制。
4. 连接、断开、停止命令的说明和反馈由英文改为中文；受 DSH 命令格式限制，保留 /rimworld-connect 等英文命令标识。
5. 插件安装由旧版 .agent-presets 目录注册改为新版 cordis.patch.yml 注册，并使用 Windows file:// 插件地址；安装、卸载脚本及中文教程同步更新。
6. 首轮上下文中逐个展开远方聚落的方式改为数量摘要和少量贸易候选，减少无关信息。
7. 蓝图信息由逐项重复展开改为数量与材料需求汇总、保留少量样本，并去除重复动态索引文字。
8. 自动最高肥力种植区由沿相连高肥力地块持续扩展改为每次最多 15×所有存活殖民者人数格，AI 与玩家殖民者合计，仍只创建一个连续区域。
9. AI 自行接取任务改为向玩家请求接取，移除对应工具及执行入口。
10. 开局自动生成垃圾储存区改为不自动生成；开局配置请求改为首次连接存档时请求玩家配置工作优先级、作息和生活方案。
11. 自动检查、自动战斗等协作行为由仅安装 Mod 即可触发改为 Agent 连接后运行。
12. 外围墙由双层建设改为使用 F mapID [岩石材质] 环绕所有居住区建设单层围墙，不相连的居住区也会包围；旧 F2 命令改为兼容单层围墙，不再追加第二层。
13. 围墙强制与房屋间隔四格改为位于居住区外、不覆盖居住区，通常呈长方形或正方形，遇不可建位置绕行，保留左右两个开口。
14. 扩建围墙时保留圈内旧外围墙改为将工具记录的旧墙标记拆除、取消旧蓝图；保留新旧重合段和靠近屋顶的房间墙。拆除仍由殖民者执行，无法可靠识别的历史外墙不会自动拆除。
15. “双方可操控对方殖民者”开关改为“双方操控方式”三选项：各管各的、双方控制全部、玩家可控制 AI 但 AI 不可控制玩家。
16. 玩家手动征召触发自动溜怪改为不触发；玩家手动下达工作时改为自动战斗让出控制，不改变殖民者原归属及其他既有归属检查。

三、问题修复
1. 修复了聊天页面按 Enter 会关闭窗口而不是发送消息的 bug。
2. 修复了玩家提前聊天触发 AI 后决策计时未正确重置、下一轮过早注入的 bug；玩家聊天后重新计时，AI 正常回复完成后等待完整决策间隔。
3. 修复了新版 V4 会话拒绝旧 source.kind=plugin 消息、连接时提示“format v4 message requires a producer-owned source kind”的 bug。
4. 修复了 Windows 裸绝对路径导致新版 DSH 插件加载失败的 bug。
5. 修复了单次 CLI 管道关闭被误判为 Agent 断开的 bug，并增加短暂通信失败重试及读档后的重新握手。
6. 修复了连接过 Agent 后退出游戏可能卡死的 bug；游戏关闭或返回主菜单时进行断连，命名管道使用可取消异步连接，避免无限等待和主线程阻塞释放。
7. 修复了工具生成的围墙自身触发自动居住区向外扩张的 bug。
