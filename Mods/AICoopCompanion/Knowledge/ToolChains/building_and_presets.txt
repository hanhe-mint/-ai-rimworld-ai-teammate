# 建设、房间与预设关联链

普通房间：读取地图可建区域和现有建筑 -> `designate_area` 清理树木、矿石岩体或待拆建筑 -> 同轮先用 `dump_stockpile` 建至少 7x7 临时垃圾区，再用 `designate_area(action=haul_chunks)` 搬石块 -> `build_room` 放置一个房间 -> 读取蓝图材料缺口 -> 用伐木、采矿、搬运补料 -> 等殖民者自动施工。

预设房间：用 `REF preset list` 查看实际目录（数量不限，玩家可随时新增中文文件）-> 按名称、用途和同义词匹配需求，例如厕所对应卫生间 -> `REF preset read 卫生间.txt` 读取需要的一份 -> `PRESET 卫生间` 使用真实中文名建造 -> 未研究或未制作设施暂时跳过 -> 需要时完成前置并 `preset_retry`，稳定可用后 `preset_done`。只有用途名无需原版存在，物品Def仍必须由游戏或已启用Mod提供。先用 `REF layout list` 检查玩家成品布局，有则规划相对位置、按需逐间建；无则沿用普通规则。不要自行读取说明或示例。

外围防御：居住区边界至少13x13且建设稳定 -> `build_perimeter`/`F mapID [岩石材质]` 包围所有居住区，包括分离部分，只建一层矩形石墙；墙不占居住区，不额外要求四格，仅受不可建地形阻挡时绕行，左右留口不建门 -> `defense` 在开口外放陷阱。新圈内记录的旧外墙自动拆除指定/取消旧蓝图，重合段和房间墙保留。收到 PERIMETER_EXPANDED 后按需调整。预计精英袭击压缩前点数超过1000时，墙内使用 `主动炮台.txt`；`大门防御阵地.txt` 对齐左右开口之一，外墙长度不足则扩建。主动炮台距其他建筑至少2格。

关联限制：普通房间 13x13、单一用途。先按房间边线对齐紧贴共墙，再检查门，不为门位错开房间或换拼接侧。坐标作为选址优先位置，以结果 origin 为准；门不对齐才计算原位旋转，旋转必须经玩家同意。仍不对齐先询问，同意才强制拼接，保留已有共享墙门并请求玩家调整。WAIT 时不得重复调用或绕过确认。房间内部可在不改变用途和封闭性的前提下调整设施；防御预设保留特殊间距。材料不足是补料条件，不是重复放置蓝图的理由。
