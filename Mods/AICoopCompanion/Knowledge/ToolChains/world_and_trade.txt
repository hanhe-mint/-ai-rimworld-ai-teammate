# 世界地图、商队、运输舱与贸易关联链

所有世界地图操作先读取 `TOOL_PERMISSIONS`。允许时可执行；询问时先 `request_player` 并等待明确同意；禁止时停止。不得通过其他工具绕过。

商队：玩家要求并允许 -> 确认目的地 tile、AI 殖民者 ID 和物资 ID -> `world_caravan` 组队 -> `world_move` 设目的地 -> 到达后读取新状态。不能加入玩家殖民者。

运输舱：确认运输器 ID、载荷、燃料和目的地 -> 多次 `world_load` 装载 -> 核对装载结果 -> `world_launch` 发射。载荷或目的地被拒绝时按原始错误修正。

贸易：确认可交易世界对象和 AI 谈判者在同一 tile -> 根据设置选择 `world_trade_ui` 或 `world_trade`。窗口模式只打开原版贸易界面并请求玩家操作；自动模式按真实库存、价格和白银执行买卖，交易后重新读取结果。

任务：只有玩家明确要求且权限允许时使用 `world_quest_accept`；复杂任务目标、许可或 AI 没有工具的后续统一 `request_player`。
