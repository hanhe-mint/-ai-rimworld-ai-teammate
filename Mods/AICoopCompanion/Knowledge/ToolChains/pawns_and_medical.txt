# 人员、装备、床位与医疗关联链

装备：读取人物 Shooting、Melee、禁用工作和地图现有物品 -> 射击合格者使用 `gear(action=equip)` 装远程武器，近战合格者装近战武器 -> 穿衣使用 `gear(action=wear)` -> 游戏完成穿戴后自动取消强制穿戴。不要为开局装备建设锻造台。

床位：新成员或囚犯出现 -> 读取 `BED_CAPACITY` -> 缺床时选择相应房间预设或建设单一用途房间 -> `bed_mode` 设置 colonist、prisoner、slave 或 medical 形态 -> 再检查容量。

医疗：选择 Medicine 足够且未禁用医生工作者 -> 设置患者医疗照顾级别 -> 需要手术时确认床、药物、配方和身体部位 -> `surgery` 添加账单 -> 等原版医生执行并读取结果。

器官手术：仅限 AI 自己俘虏且不属于进行中任务保留目标的囚犯 -> `organ_harvest` 一次建立肺、肾、心脏的固定顺序，心脏不能摘才用肝 -> 来源不明或任务状态不清时先 `request_player`。

工作优先级用 C mapID work pawnID 1,3,0,... 一次提交该 AI 殖民者的完整序列。按 WORK_PRIORITY_ORDER 排序，各项 0-4，禁用工作填 0；技能不足的工作不要设置 1/2。先检查全组再应用，不分多轮逐项设置。
